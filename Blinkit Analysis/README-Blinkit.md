# Blinkit Dashboard (DSB)

## Overview
A Power BI dashboard analyzing sales and delivery data for Blinkit, the quick-commerce grocery delivery platform. Built to understand order patterns, product performance, and outlet-level sales.

## Objective
Give a clear view of how products and outlets are performing so decisions on stocking, pricing, and outlet strategy can be data-driven instead of guesswork.

## Tools Used
- Power BI (data modeling, DAX, Power Query)
- Excel (data prep)

## What the Dashboard Covers
- Total sales and item count by product category
- Outlet-wise sales performance and ratings
- Fat content / product-type breakdown
- Sales trends by outlet size and location type
- Interactive filters for category, outlet, and location

## Key Skills Demonstrated
- Retail/FMCG data analysis
- DAX measures for sales and item metrics
- Categorical breakdown and comparison visuals
- Dashboard design for quick-commerce/retail use cases
