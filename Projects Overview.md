# Projects

Power BI and Excel dashboards built to practice a full data analytics workflow — cleaning raw data, modeling it, and turning it into dashboards that actually answer business questions.

**Tools used:** Power BI (DAX, Power Query), Microsoft Excel

## Dashboards in this repo

### Airlines
Dashboard analyzing airline operations and performance data — flight-level metrics, delays, and trends.

### Amazon Sales & Performance Reports
Sales and performance dashboard for Amazon-style e-commerce data — revenue, orders, and category-level breakdowns.

### Awesome Chocolate
Sales dashboard tracking product, region, and channel performance for a chocolate company.

### Blinkit DSB
Dashboard analyzing Blinkit (quick-commerce) sales and delivery data.

### Financial Loan Report
Loan portfolio dashboard — tracks applications, approvals, and loan performance metrics.

### Healthcare Analysis
Dashboard analyzing healthcare data — patient, treatment, or hospital-level metrics.

### OLA Report
Ride-hailing dashboard analyzing OLA trip data — bookings, cancellations, and revenue trends.

### Superstore Sales Analysis
Classic retail sales dashboard — profit, discount, and regional performance analysis on the Superstore dataset.

### ZeptoDSB
Dashboard analyzing Zepto (quick-commerce) sales and delivery data.
