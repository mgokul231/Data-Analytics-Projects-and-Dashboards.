# Airlines Dashboard

## Overview
A Power BI dashboard built to analyze airline operations data — flights, routes, delays, and overall performance. The goal was to turn raw flight records into a report that shows where the airline is losing time and money, and where it's performing well.

## Objective
Give a clear, at-a-glance view of flight performance so decision-makers can spot delay patterns, busy routes, and operational bottlenecks without digging through raw data.

## Tools Used
- Power BI (data modeling, DAX, Power Query)
- Excel (initial data cleaning)

## What the Dashboard Covers
- Flight volume by route, airline, and time period
- On-time vs delayed vs cancelled flight breakdown
- Delay trends over time (by month, day, or hour)
- Route- and airline-level performance comparison
- Interactive filters/slicers to drill into specific routes or date ranges

## Key Skills Demonstrated
- Data cleaning and transformation in Power Query
- DAX measures for KPIs (on-time %, average delay, etc.)
- Dashboard layout and interactivity design
- Turning operational data into decision-ready visuals
