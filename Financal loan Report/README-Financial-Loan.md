# Financial Loan Report

## Overview
A Power BI dashboard analyzing a bank's loan portfolio — applications, approvals, repayments, and risk. Built to give a lending team a clear picture of loan health at a glance.

## Objective
Track how the loan book is performing: how much is being lent, how much is coming back, and where default risk is concentrated.

## Tools Used
- Power BI (data modeling, DAX, Power Query)
- Excel (data prep)

## What the Dashboard Covers
- Total loan applications, funded amount, and amount received
- Good loans vs bad loans (default/charged-off) breakdown
- Loan status trends over time
- Loan purpose, term, and grade-wise analysis
- Interest rate and DTI (debt-to-income) trends
- Interactive filters by loan status, term, and purpose

## Key Skills Demonstrated
- Financial data analysis and risk-metric tracking
- DAX measures for approval rate, default rate, and funded amount
- KPI card and trend visualization design
- Handling and modeling large transactional datasets
