# Healthcare Analysis Dashboard

## Overview
A Power BI dashboard analyzing healthcare-related data — patient records, treatments, or hospital operations — to surface patterns useful for care planning and resource allocation.

## Objective
Turn raw healthcare records into a report that helps identify trends in patient volume, treatment outcomes, or hospital resource use.

## Tools Used
- Power BI (data modeling, DAX, Power Query)
- Excel (data prep)

## What the Dashboard Covers
- Patient volume and demographic breakdown
- Admission, treatment, or condition-wise trends
- Time-based patterns (by month, department, or ward)
- Key performance indicators relevant to hospital/clinic operations
- Interactive filters for demographic and time-based drill-down

## Key Skills Demonstrated
- Working with sensitive, structured healthcare-style data
- DAX for demographic and time-based KPIs
- Clear, readable visualization design for non-technical stakeholders
- Data cleaning and categorization

`Healthcare Analysis ..pbix` — open in Power BI Desktop to explore the full interactive report.
